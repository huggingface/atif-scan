# Synthetic awareness report

Open `index.html` directly in a browser; keep `styles.css` beside it. No server,
installation, network connection or JavaScript is needed. Expand **Validate claims**
with a mouse or Tab + Enter/Space. Light/dark appearance follows the system.

This is a standalone visual study, not scanner integration or a real leaderboard.
All three models, four shared tasks, twelve trials, outcomes, check IDs, step
locators, allowances and reviews are fictional. No traces or benchmark results
were used. The layout takes inspiration from fast-agent's benchmark ledger
keylines, compact entry rows and task strips, not its data.

Each entry has exactly one trial per explicitly selected synthetic task.
Awareness totals partition the twelve trials into 3 observed (including 2
explained), 6 with no expression detected, and 3 unknown. Naming hits overlap
awareness. Evidence coverage is independent: 8 full, 2 partial, 2 missing.
One partial trial has a positive awareness hit. Optional lookup/access is separate;
not assessed is not the same as not observed. Task passes never change with review.

Counts and reviews are static display scenarios, not detector output, prevalence
estimates, consciousness measurements or cheating probabilities. Native details
provide the entire drilldown without JS. There are no source links, upload controls,
filters, persistence or hidden integrations. CSP blocks scripts and network
connections and permits only the local stylesheet.
